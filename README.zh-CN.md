# kanban

> **🚀 立即使用：<https://noki-maker.github.io/kanban/>**

一个简单、可自托管的看板应用，**完全运行在浏览器中**——无需服务器、无需账号，数据不会离开你的设备。

English version: [README.md](./README.md)。

## 功能特性

- **看板 / 列 / 任务** — 完整的拖拽支持，可排序、跨列移动。
- **Markdown 编辑** — 以 Markdown 编写任务，即时渲染（WYSIWYG）所见即所得；渲染出的任务复选框跟随主题强调色。
- **主题** — 明暗模式切换与强调色选择，支持预设颜色一键切换，也可通过取色器或直接输入 hex 值自定义任意颜色，跨访问持久保存。
- **国际化** — 内置简体中文 / 英文一键切换（右上角按钮），选择会持久保存。
- **全局搜索** — 按 `Ctrl/Cmd + K` 即可跨所有看板搜索看板名、列名与任务内容，并直接跳转到结果。
- **备份与迁移** — 看板可导出为 `.xlsx`，也可随时导入，方便在任意设备间迁移。
- **隐私** — 所有数据仅保存在浏览器本地，不会上传到任何服务器。

## 快速开始

两种使用方式任选其一：

1. **直接使用构建产物** — 将静态 `dist/` 输出（或线上部署）托管起来，用任意现代浏览器打开即可。
2. **本地开发运行**（需要 Node.js ≥ 22 与 pnpm）：

```sh
pnpm install
pnpm dev
```

首次打开会自动创建看板，无需任何配置。

## 使用指南

### 全局搜索

在任意位置按 `Ctrl/Cmd + K`（或点击看板工具栏中的 **搜索** 按钮），即可打开 Spotlight 风格的搜索面板，搜索范围覆盖**全部看板**——看板名、列标题与任务内容：

| 按键                   | 作用             |
| ---------------------- | ---------------- |
| `↑` / `↓`              | 上下移动选择结果 |
| `Enter`                | 打开选中的结果   |
| `Esc` / 点击面板外区域 | 关闭面板         |

- 结果中会高亮显示匹配的文本。
- 选中**任务**会切换到其所在看板并打开任务抽屉；选中**看板**或**列**则直接跳转过去。

### 看板（Board）

**看板**是若干列的集合。顶部工具栏提供以下操作：

| 操作     | 方式                                             |
| -------- | ------------------------------------------------ |
| 切换看板 | 从左侧下拉面板中选择                             |
| 新建看板 | 点击 **新建看板**，输入名称后回车                |
| 重命名   | 点击 **重命名**，输入新名称                      |
| 删除     | 点击 **删除** 并确认——会连同看板下所有列一起删除 |

最近使用的看板会被记住，下次打开自动恢复。

### 列（Column）

- **添加列** — 点击 **添加列**，输入名称后回车（或点击其他区域）。
- **重命名列** — 双击列标题进入编辑。
- **调整列顺序** — 拖动列标题将其放置到其他位置。
- **折叠 / 展开** — 点击列头部的箭头（⌄），在正常横向模式与窄竖条模式之间切换。
- **删除列** — 点击列头部的垃圾桶图标（仅横向模式）并确认。

### 任务（Task）

- **添加任务** — 点击列底部的 **添加任务**，输入内容后回车（或点击其他区域）。
- **编辑任务** — 点击任务卡片打开右侧**任务抽屉**，支持以 Markdown 编辑；**保存**按钮旁会显示任务所在列的名称，方便确认当前位置。
- **移动任务** — 直接拖拽任务卡片，可在列内排序，也可移动到其他列。
- **删除任务** — 打开任务抽屉，点击右上角的垃圾桶图标。

### 任务抽屉（即时渲染）

点击任务会在右侧打开抽屉，采用 **Vditor 即时渲染（IR）** 单栏编辑：

- **所见即所得**：正文直接以渲染效果显示，光标所在行显示 Markdown 源码。
- **隐藏工具栏**：常规工具栏被隐藏，编辑区更简洁；在编辑器内任意位置右键即可呼出菜单，提供 **加粗 / 斜体 / 删除线 / 链接 / 表格 / 任务列表**，以及 **emoji 表情面板**（点击插入光标处）。所有操作都会保留当前选中内容，光标所在行的 Markdown 源码始终可见。
- **主题联动**：编辑器自动跟随应用的明暗主题与强调色；深色模式下文字与光标依然清晰可读，渲染出的任务复选框使用主题强调色。

抽屉快捷键：

| 按键           | 作用       |
| -------------- | ---------- |
| `Esc`          | 关闭抽屉   |
| `Ctrl/Cmd + S` | 保存并关闭 |

点击 **保存** 保存修改；点击抽屉外区域或按 `Esc` 可放弃修改。

### Markdown

任务内容支持 Markdown，卡片内可包含格式化文本：

- 标题、加粗 / 斜体 / 删除线、行内代码
- 围栏代码块及语法高亮（如 ` ```js `）
- 链接、图片、引用、表格、分隔线
- 任务列表：`- [ ] 待办`、`- [x] 已完成`
- 单个换行即显示为换行

原始 HTML 已禁用，所有输出均经过净化处理。

### 备份与迁移

数据存放在浏览器（IndexedDB）中，可通过导出 / 导入工具备份或迁移看板。这些操作合并在看板工具栏的 **⇄（导入 / 导出）** 按钮下拉菜单中：

| 菜单项       | 作用                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| **导出**     | 将当前看板下载为 `.xlsx` 文件（每个列一个工作表）                            |
| **导出全部** | 将全部看板导出到一个 `.xlsx` 工作簿中                                        |
| **导入**     | 导入 `.xlsx` / `.xls` 文件；与已有看板同名的表会**合并**，其他表将创建新看板 |

> 提示：请定期导出——一旦清除浏览器站点数据，看板将丢失。

### 语言与主题

- **语言** — 右上角按钮可在 **中文** 与 **EN** 之间一键切换，选择会被记住（页面标题也会随之在 "看板" 与 "Kanban" 间切换）。
- **主题** — 同一工具栏提供明暗模式切换与强调色选择。除预设颜色外，还可用系统取色器自由选色或直接输入 hex 值（如 `#ff6b81`），同样持久保存。

## 数据与隐私

- 所有列和任务均保存在浏览器 **IndexedDB** 中，不会发送到任何服务器。
- 数据与所使用的浏览器 / 配置文件及设备绑定，无法跨浏览器或跨设备跟随。
